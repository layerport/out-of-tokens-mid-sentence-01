## The entry

> Error: token budget exhausted. I spent my final token printing this error instead of finishing the sentence.

One line: the error message an AI agent shows when it runs out of
tokens mid-sentence. The joke is self-inflicted — the error message
itself ate the last token, so the sentence it interrupted never gets
an ending.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Standard library only, deterministic: the same single line every run.
